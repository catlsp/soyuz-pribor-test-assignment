# Сопроводительное сообщение

Здравствуйте! Направляю выполненное тестовое задание: CLI-приложение на Python для генерации B2B-описаний промышленной продукции с проверкой структуры и ограничением на неподтверждённые числовые характеристики.

В репозитории есть инструкция по запуску, описание промптов и решений, примеры результатов в JSON/Markdown, 19 автоматических тестов и GitHub Actions. Технические характеристики формируются непосредственно из входных данных; модель пишет текстовые блоки, которые проходят проверку структуры, длины и новых числовых значений. Недостающие сведения явно отмечаются.

Полные данные двух товаров не предоставлены. Поэтому использованы фрагмент с манометром DM 02 из задания и явно обозначенный синтетический неполный пример. Реальная генерация проверена через OpenAI-совместимый API CheapVibeCode с моделью `gpt-6-luna`: оба ответа прошли проверку структуры и длины. В репозитории сохранены исходный ответ и явно обозначенный пример после редакторской проверки. Дополнительно доступен демо-режим без ключа; автоматические тесты не требуют сети.

Главное ограничение: числовая проверка не доказывает фактическую достоверность всех формулировок, поэтому черновики требуют редакторской проверки. Возможные улучшения описаны в документации.
