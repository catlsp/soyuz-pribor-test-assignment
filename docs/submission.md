# Сопроводительное сообщение

Здравствуйте! Направляю выполненное тестовое задание: CLI-приложение на Python для подготовки B2B-карточек промышленной продукции по исходным данным.

В проекте есть инструкция по запуску, описание промптов и проектных решений, JSON/Markdown-примеры и автоматические проверки. Модель формирует план из разрешённых фактов и советов, а программа собирает текст из исходных значений и проверяет результат. Недостающие характеристики отмечаются явно. Для запуска без ключа предусмотрен демонстрационный режим.

В исходном задании перечислены два товара, однако полные исходные данные предоставлены только для фрагмента с манометром DM 02. Второй товар в примерах заменён явно обозначенным синтетическим неполным вводом; его нельзя считать выполненной карточкой реального изделия.

Текущая версия проверена реальным вызовом OpenAI-совместимого API CheapVibeCode с моделью `gpt-6-luna`: описания имеют длину 838 и 851 символ, обе карточки укладываются в требования. Актуальные результаты без ручной правки сохранены в `examples/results.llm.checked.json` и Markdown. Автоматические тесты и GitHub Actions работают без ключа и сети.

Ограничения и сверка требований описаны в README и документации проекта.
