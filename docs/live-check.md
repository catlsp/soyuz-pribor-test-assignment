# Проверка реального LLM-вызова

Пользователь выполнил команду без `--demo` на двух объектах из `examples/inputs.json`. Настройки прогона: `OPENAI_BASE_URL=https://cheapvibecode.ru/v1`, `OPENAI_MODEL=gpt-6-luna`, `OPENAI_TIMEOUT=120`. Ключ передавался через окружение и в результаты не включён. Программа использовала Chat Completions и режим `json_object`.

Результат: две карточки с `mode=LLM`, SEO-заголовками до 70 символов, описаниями 1011 и 936 символов и четырьмя поисковыми запросами для каждой карточки. Структурированные характеристики и список пропусков сверены с входными данными. Неизменённый результат программы: [results.llm.raw.json](../examples/results.llm.raw.json).

## Редакторские замечания

В первом описании модель добавила формулировки о получении показаний «непосредственно по шкале» и работе «без подключения к сложным средствам отображения». Во входных данных эти утверждения явно не подтверждены. Они прошли числовую проверку, поскольку не содержат новых чисел. Поэтому успешная валидация не означает полную фактическую достоверность текста.

Для примера после редакторской проверки первое описание переписано по подтверждённым данным: назначению, диапазону, классу точности, присоединению и диаметру корпуса. Второе описание оставлено без изменений. Обе карточки имеют метку `LLM + редакторская проверка`, чтобы отличать их от необработанного вывода программы. JSON и Markdown: [results.llm.json](../examples/results.llm.json), [results.llm.md](../examples/results.llm.md).

Эта редактура выполнена отдельно от программы и не является автоматической защитой от качественных галлюцинаций. Данные второго товара по-прежнему являются явно синтетическим неполным вводом.

## Как повторить

Задайте ключ провайдера в `OPENAI_API_KEY`, затем выполните в PowerShell из корня проекта:

```powershell
$env:OPENAI_BASE_URL = 'https://cheapvibecode.ru/v1'
$env:OPENAI_MODEL = 'gpt-6-luna'
$env:OPENAI_TIMEOUT = '120'
python -m product_copywriter examples/inputs.json --format json --output results.llm.json
```

Проверьте код завершения, поле `mode`, длины текстов, соответствие характеристик и содержание каждого утверждения. Повторная генерация может дать другой текст. Наличие модели у провайдера проверяется отдельно; успешный сохранённый прогон не гарантирует доступность модели в будущем.
